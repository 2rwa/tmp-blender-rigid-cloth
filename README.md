# tmp-blender-rigid-cloth

Public sandbox for Blender rigid-body, cloth, collision, and related physics experiments.

This repository is split out from `2rwa/tmp-blender` so heavier or longer-running physics/rendering experiments can evolve independently.

## Goals

- Reuse the useful Blender/CI/rendering infrastructure from `2rwa/tmp-blender`.
- Experiment with rigid bodies, cloth, collisions, and combinations of them.
- Keep reproducible scripts, workflows, notes, and rendered test outputs together.
- Use GitHub Pages for browser-visible test/result pages where useful.

## Continuation source

Development should follow the continuation prompt maintained in:

- repo: `2rwa/chatgpt-workspace`
- path: `prompts/tmp-blender-continuation-prompt.md`

The repository will be populated from `tmp-blender` selectively rather than copied wholesale.
